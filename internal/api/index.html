BACnet/IP REST Proxy

This service provides a REST interface to BACnet/IP devices: clients use HTTP calls to query and update BACnet objects, which are translated into the corresponding BACnet/IP messages and sent to the target device. Access is controlled through HTTPS, authentication and authorization rules. See the API reference or the OpenAPI specification. Source code and documentation are available at github.com/stblassitude/bacnet-ip-rest-proxy.
